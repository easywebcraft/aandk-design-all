## 料金（★ここを間違えた）

**21,000円／月の「3サイト」は、保育園サイト／放課後等デイサイト（KIDS・SMILE
共通の1サイト）／aandkcorp.com の3つ**。ユーザーに確認済みで、この額で提案済み。

**`kaminote-proposal/src/proposal-kaminote.html` の記載とは食い違っている。**
あちらの03節は「3サイト案＝保育園・かみのてKIDS・かみのてSMILE」「2サイト案＝
保育園・放デイ1つ／17,000円」と書いてあるが、**実際の合意はそれとは別**。
最初その記載を信じて写し、aandkcorp.com を9,800円の別建てにして合計30,800円と
書いてしまった（誤り）。**資料に書いてあることを実際の合意より優先しないこと。**

かみのて提案書の料金表は 2026-09-06 時点で未修正のまま（ユーザーが
「今日の内容は反映しないで」としているため触っていない）。要確認事項。

`kaminote-proposal/design.html`（かみのて2サイトの決定用）には
**コーポレートサイトを載せない**。あちらは案を決めていただくための資料で、
構想段階のものを混ぜると何を決める場か分からなくなる。

## 編集のしかた

原本は `src/design-all.html`。`build.py` が viewport・リセットCSS・OGP・noindex を
被せて `index.html` を作る。**生成物を直接編集しないこと。**

```bash
cd ~/aandk-design-all && python3 build.py
```

意匠と外枠は `kaminote-proposal/src/design-kaminote.html` から複製している。
**あちらを直しても自動では追随しない。**
